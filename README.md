
# PIC16F877A MCU - Interfacing with mikroC

## Overview
This repository contains a collection of embedded system applications and hardware interfacing modules for the **PIC16F877A** microcontroller. The firmware is written in Embedded C using **mikroC PRO for PIC**, focusing on practical implementations of essential peripherals and control systems.

## Included Modules & Projects

*   **PWM (Pulse Width Modulation):**
    Demonstrates the configuration and generation of PWM signals, useful for applications like DC motor speed control or LED dimming.
*   **LCD (Liquid Crystal Display):** 
    Contains drivers and routines for initializing and displaying text/data on standard alphanumeric LCD modules.
*   **7-Segment Display:** 
    Implementation of numerical output displays using 7-segment components, including multiplexing techniques.
*   **Secure System:** 
    A comprehensive access control project that integrates multiple peripherals (such as Keypad and LCD) to create a password-protected lock or security system.

## Tools & Technologies
*   **Microcontroller:** Microchip PIC16F877A
*   **Compiler/IDE:** mikroC PRO for PIC
*   **Simulation:** Proteus (ISIS)

## How to Use
1. Clone the repository to your local machine.
2. Open the `.mcppi` project files using mikroC PRO for PIC.
3. Compile the code to generate the `.hex` file.
4. Load the `.hex` file into the Proteus simulation or burn it directly to the PIC16F877A hardware.
